# 名渡 Namebridge

给海外华人父母的宝宝取名工具。中文名的字义、出处、谐音、连读，和**英语母语者会怎么念这个拼音**，放在同一个界面里看。

完全在浏览器本地运行：没有后端，没有 API Key，不收集任何数据，不需要注册。

## 它解决什么问题

在海外给孩子取名，要同时过两关，而市面上的工具通常只管一关：

1. **中文这一关**：字义要正、出处要真、姓和名连读不能出事故、别撞上班里的爆款字。
2. **英语这一关**：孩子每天要被老师和同学念名字。拼音里的 `x`、`q`、`ü`、`zh` 在英语里根本没有对应音，会被稳定地念错十几年。

名渡把两关的判断都写成**可以核对的条目**，而不是一个说不清来历的分数。

## 主要功能

| 功能 | 说明 |
|---|---|
| 即时出名字 | 填一个姓就出结果，其余条件随时再调，不用走完向导 |
| 英语可读性 | 具体告诉你「旭 Xu 会被念成 Zoo」，而不是简单地不推荐 |
| 谐音检查 | 98 条规则，按「姓 + 名」的完整读音比对，严重的直接剔除 |
| 真实出处 | 96 句公有领域典籍，两个字确实同出一句、且字序一致才标注 |
| 四柱五行 | 用天文算法求真节气排八字，含真太阳时校正；只做历法换算，不做命运判断 |
| 英文名配对 | 239 个英文名，标注发音、误读风险、昵称牵引和当下流行度 |
| 英文全名检查 | 首字母缩写、头韵、音节节奏 |
| 分享链接 | 整份名单编码进 URL，长辈点开就能看，不经过任何服务器 |
| 心选与比较 | 收藏、加备注、最多四个并排比较 |
| 备份 | 导出/导入 JSON，导入是合并去重，不覆盖已有数据 |
| AI（可选） | 自带 OpenRouter Key，用免费模型：一句话设条件、解读名字、点评心选 |

## 两个技术上认真做了的地方

**节气是算出来的，不是查表的。** 节气的定义是太阳视黄经每走满 15° 的那一刻，是天文量。这里用 Meeus《Astronomical Algorithms》的太阳位置公式配合 ΔT 修正求解，和《中国天文年历》公布值对照，误差在 1–12 分钟内（[测试](src/engine/bazi.test.ts)）。出生时刻压在交节点附近时，界面会提醒去查权威万年历。

**真太阳时校正会真的改变时柱。** 奥克兰在东经 174.76°，而 UTC+12 的中央经线是 180°，两者差 21 分钟。晚上 23:10 出生的孩子，按钟表是子时，按真太阳时还在亥时——日柱和时柱都不一样。收录了 101 个海外华人常住城市的经度与时区（夏令时由 `Intl` 自动处理）。

## AI 是可选的，而且刻意只当表达层

默认关闭，不开它整个网站完全离线。开启需要你自己的 [OpenRouter](https://openrouter.ai/keys) Key，用免费模型不需要充值 —— 免费模型名单变动很勤，所以列表是每次打开时实时拉取并筛选的，不硬编码。

设计上守住一条线：**AI 负责表达，判断仍然由本地引擎给出。**

- 「说一句话设条件」把你的描述翻译成筛选条件，名字仍由本地引擎生成。AI 返回的每个字段都经过白名单校验，枚举值不认识就丢掉、必含字不在字库里就丢掉，并当场告诉你丢了什么（[校验器](src/ai/applyIntent.ts) 与它的 [13 条测试](src/ai/applyIntent.test.ts)）。
- 「解读名字」和「点评心选」的提示词里明确禁止编造典故和出处 —— 资料里没出处，它就得说没有。

开启 AI 意味着数据会离开设备：你写的描述原文、让 AI 解读的名字、让 AI 点评的名单（含备注）会发给 OpenRouter 和所选模型提供商。**出生日期、时间、城市和排出来的八字不会随这些功能发出去**。API Key 只存在本机浏览器，也不写进导出的备份文件。

## 说清楚做不到什么

- 没有公安户籍系统的实时规范字库——生僻字能不能上户口，只有派出所说了算
- 没有全国重名数据库——「少见用字」是基于用字频率的估计
- 不做八字旺衰喜忌的判断，那需要真正的命理师
- 没有跨设备云同步——数据只在本机，换设备请用导出备份

## 技术栈

React 19 + TypeScript + Vite，手写 CSS（无 UI 框架），Vitest + Testing Library。
无运行时依赖，无后端。推送到 `main`/`master` 后由 GitHub Actions 自动部署到 Pages。

## 数据来源

- 取名用字 378 个，另有人工精选的双字名 415 个；五行按字形部首归类（这只是众多流派中的一种，界面里有说明）
- 典籍 96 句，全部为先秦至宋代的公有领域文本；其中 13 句讲凋零、离别、死亡的做了标记，永不引用
- 英文名 239 个，含义与语源为公开的语言学事实
